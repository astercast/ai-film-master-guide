Prompt tips for this model

  • Plates carry the look. Image models make your keyframes and character sheets, lock them with the character-consistency system and describe them with the prompt anatomy.
  • Style is the brief. Aesthetic models reward precise visual language, cinematic language for the vocabulary.
  • Run it through the linter. Paste any prompt for this model and check all ten layers before spending credits.
  • Not sure it's the right model? Take the 5-question quiz or compare it side-by-side with alternatives.
