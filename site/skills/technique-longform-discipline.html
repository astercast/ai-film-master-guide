Guide / Skills / The Path, stage 2

Apply long-form discipline to shorts

Gets you: Your short film will hold together like a long one: every shot mapped, identities locked, drafts cheap, no character or room changing between shots.

What this is
Use the habits that keep long AI films consistent, map every shot, lock identities, draft cheap, on a short film, so your characters and rooms stop changing between shots.
First step
Map every shot before generating, lens, light, character state per shot.
You will need
Frame map (even a sketch); Asset registry (even a short list)
Time
About 3 minutes for a first run-through (4 steps; estimated from the procedure itself, your model’s generation time is extra).
Level
Beginner, made to be usable on a first project.
Before this
Best after the skill before it on the Path (skill 75 of 241: Direct a photoreal character piece), but everything it needs is listed below, and nothing else is assumed.
Proof: the worked example
20-min ONEIRIC ran 41,118 assets with a color-coded frame map, the same habits scale down.

Use when

Any multi-scene short where consistency matters (which is most of them).

Inputs

  • Frame map (even a sketch)
  • Asset registry (even a short list)

Procedure

  1. Map every shot before generating, lens, light, character state per shot.
  2. Separate identity from motion in every prompt.
  3. Validate at 720p; upscale winners only.
  4. Re-anchor references every few generations; J/L cuts + ambience bed for transitions.

Worked example

20-min ONEIRIC ran 41,118 assets with a color-coded frame map, the same habits scale down.

API references

  • data/v1/checklists.json

Pitfalls

  • Skipping the map 'because it's short', 3 minutes still has 40+ shots.
