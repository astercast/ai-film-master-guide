Fix morphing faces

Gets you: A face that keeps melting or changing mid-shot will hold still and stay the same person.

What this is
Diagnose and fix faces that shift between frames or shots.
First step
Confirm the face anchor is attached and attached LAST (photos win the style vote).
You will need
The failing clip; The face anchor reference
Time
About 3 minutes for a first run-through (5 steps; estimated from the procedure itself — your model’s generation time is extra).
Level
Beginner — made to be usable on a first project.
Before this
Best after the skill before it on the Path (skill 208 of 241: Prompt: Plasticky wide-shot fix) — but everything it needs is listed below, and nothing else is assumed.
Proof — the worked example
Crowd shot morphing → re-cut as three single-face shots → locked.

In plain words

morphing / face-morph
morphing (a face-morph) — a face warping or melting as it changes between frames; a common AI-video flaw. A 'face-morph rescue' repairs a shot where it happened.

Use when

Any generation where the face won't hold.

Inputs

  • The failing clip
  • The face anchor reference

Procedure

  1. Confirm the face anchor is attached and attached LAST (photos win the style vote).
  2. Shorten the shot — morphing compounds with duration.
  3. Reduce competing faces: one face per shot beats a crowd.
  4. For recurring characters, lock identity (Soul ID) instead of describing.
  5. Fix in post as last resort: face refinement passes on hero shots only.

Worked example

Crowd shot morphing → re-cut as three single-face shots → locked.

Pitfalls

  • Re-rolling the same prompt — change the anchor position or the shot length.
