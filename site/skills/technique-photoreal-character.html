Guide / Skills / The Path, stage 2

Direct a photoreal character piece

Gets you: You will have a realistic short that feels acted rather than generated: a real script, one point of view, faces carrying the story.

What this is
Make a realistic-looking short that feels acted, not generated: start from a real script and shoot every scene from one character's point of view.
First step
Start from a script with dialogue and turns, writing is the cheapest VFX.
You will need
A real screenplay (or adapted scene); POV plan: whose eyes, every shot
Time
About 3 minutes for a first run-through (4 steps; estimated from the procedure itself, your model’s generation time is extra).
Level
Beginner, made to be usable on a first project.
Before this
Best after the skill before it on the Path (skill 74 of 257: Commit to an authored style), but everything it needs is listed below, and nothing else is assumed.
Proof: the worked example
A Face Only a Mother Could Love: old screenplay + tight POV discipline, double Grand Prix.

Use when

Intimate, character-driven photoreal shorts, the kind where the audience must believe a person.

Inputs

  • A real screenplay (or adapted scene)
  • POV plan: whose eyes, every shot

Procedure

  1. Start from a script with dialogue and turns, writing is the cheapest VFX.
  2. Hold one POV ruthlessly; every shot answers 'whose eyes are we in?'
  3. Favor tight shots: close-ups carry performance, wides expose geometry.
  4. Cast models to the job: portrait models for faces, motion models for bodies.

Worked example

A Face Only a Mother Could Love: old screenplay + tight POV discipline, double Grand Prix.

API references

  • data/v1/models.json

Pitfalls

  • Beautiful wides with nobody in them, pretty, forgettable, unplaced.
