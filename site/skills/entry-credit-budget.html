Budget credits for a competition entry

Gets you: You will know how many credits a competition entry really takes, so a 3 to 5 minute film does not run out of money at minute two.

What this is
Credit math for a 3 to 5 minute competition entry.
First step
Clean pass = seconds × rate. 4 min at $0.35/s (720p app) = $84 clean.
You will need
Target runtime; Model mix + per-second rates; Re-roll multiple
Time
About 3 minutes for a first run-through (4 steps; estimated from the procedure itself, your model’s generation time is extra).
Level
Beginner, made to be usable on a first project.
Before this
Best after the skill before it on the Path (skill 234 of 241: Assemble the delivery package), but everything it needs is listed below, and nothing else is assumed.
Proof: the worked example
4-min entry, Seedance 720p: $84 clean → ~$600 realistic with 7× overhead + supervision reserve.

Use when

Planning spend before generating.

Inputs

  • Target runtime
  • Model mix + per-second rates
  • Re-roll multiple

Procedure

  1. Clean pass = seconds × rate. 4 min at $0.35/s (720p app) = $84 clean.
  2. Multiply by 5 to 10× for a competition-grade entry ($420 to $840).
  3. Reserve 20% for the generation-supervision pass after the rough cut.
  4. Draft at 480p where the creative question allows it.

Worked example

4-min entry, Seedance 720p: $84 clean → ~$600 realistic with 7× overhead + supervision reserve.

API references

  • data/v1/models.json

Pitfalls

  • Spending the supervision reserve on early re-rolls, protect it.
