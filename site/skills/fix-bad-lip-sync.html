Fix bad lip sync

Gets you: Dialogue that looked dubbed will line up with the voice, by routing it through the sync path that fits the scene.

What this is
Route dialogue through the right sync path.
First step
Short lines: native in-prompt quotes (dialogue quoted + attributed).
You will need
The dialogue lines; Current sync method
Time
About 3 minutes for a first run-through (4 steps; estimated from the procedure itself, your model’s generation time is extra).
Level
Beginner, made to be usable on a first project.
Before this
Best after the skill before it on the Path (skill 224 of 257: Fix identity drift across scenes), but everything it needs is listed below, and nothing else is assumed.
Proof: the worked example
12-line scene: native quotes failed at line 7 → isolated vocal → post lip-sync → locked.

In plain words

lip sync
Lip sync, Matching mouth movement to dialogue; done natively in-video (quoted dialogue) or as a post pass (Kling/Pika/Higgsfield tools).

Use when

Talking shots where mouths don't match words.

Inputs

  • The dialogue lines
  • Current sync method

Procedure

  1. Short lines: native in-prompt quotes (dialogue quoted + attributed).
  2. Long scenes: post lip-sync tools with isolated vocals.
  3. Isolate vocals before any lip-sync pass, music beds confuse the tracker.
  4. If the mouth is close but soft, it's acceptable; if it's wrong, re-route, don't re-roll.

Worked example

12-line scene: native quotes failed at line 7 → isolated vocal → post lip-sync → locked.

API references

  • data/v1/models.json

Pitfalls

  • Re-rolling video to fix audio, wrong layer, wrong cost.
