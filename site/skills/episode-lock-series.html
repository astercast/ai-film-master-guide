Guide / Skills / The Path, stage 5

Lock a mini-drama series bible

Gets you: You will have the written bible for a short episode series, title, premise, cast with voices and looks locked, that every episode is made from.

What this is
Set up the series record the episode planner persists: title, logline, hashtag, and the cast with voice IDs + one-line visual anchors.
First step
Write the series record: title, logline, hashtag, the hashtag is the distribution handle, lock it early.
You will need
Series title; One-line logline; Hashtag; Cast: name + TTS voice ID + one-line fixed visual anchor per character
Time
About 3 minutes for a first run-through (4 steps; estimated from the procedure itself, your model’s generation time is extra).
Level
Beginner, made to be usable on a first project.
Before this
Best after the skill before it on the Path (skill 188 of 257: Land the finale button), but everything it needs is listed below, and nothing else is assumed.
Proof: the worked example
Title 'Night Shift', hashtag #nightshift, cast: Rin the night-shift barista, voice avocado_v2:RIN_01, anchor 'woman, late 20s, black bob, green apron'.

Use when

Starting any serialized short-form series, nothing shoots until the bible is locked.

Inputs

  • Series title
  • One-line logline
  • Hashtag
  • Cast: name + TTS voice ID + one-line fixed visual anchor per character

Procedure

  1. Write the series record: title, logline, hashtag, the hashtag is the distribution handle, lock it early.
  2. One cast row per character: name, voice ID (e.g., avocado_v2:MAI_03), anchor (one fixed visual line, never changes across episodes).
  3. Persist as the planner's state shape (localStorage 'afg-episode-series'): {title, logline, hashtag, cast:[{name,voice,anchor}], blocks:{}, log:[]}.
  4. Anchor rule: the anchor is the continuity contract, if it drifts, the character drifts.

Worked example

Title 'Night Shift', hashtag #nightshift, cast: Rin the night-shift barista, voice avocado_v2:RIN_01, anchor 'woman, late 20s, black bob, green apron'.

API references

  • data/v1/checklists.json

Pitfalls

  • Locking episodes before the cast anchors, every later fix costs 10x.
  • Vague anchors ('a barista'), the anchor must be a fixed visual description, not a role.
