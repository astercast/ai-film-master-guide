Guide / Skills / The Path, stage 6

Unify before grading

Gets you: All your shots will match each other, same light, same colour world, before any creative look is applied, so the film stops looking stitched from different cameras.

What this is
Match every shot to a per-scene reference before any creative look.
First step
Per scene: match exposure, white balance, and contrast curve to the reference, scopes, not eyes.
You will need
Locked picture; One hero reference still per scene
Time
About 3 minutes for a first run-through (4 steps; estimated from the procedure itself, your model’s generation time is extra).
Level
Beginner, made to be usable on a first project.
Before this
Best after the skill before it on the Path (skill 228 of 257: Fix muddy AI audio), but everything it needs is listed below, and nothing else is assumed.
Proof: the worked example
14-shot kitchen scene unified to one reference still in 40 minutes, then the look took 10.

Use when

Start of the color pass.

Inputs

  • Locked picture
  • One hero reference still per scene

Procedure

  1. Per scene: match exposure, white balance, and contrast curve to the reference, scopes, not eyes.
  2. Match saturation (AI generations vary wildly).
  3. Only then apply the creative look.
  4. Consider a pre-generation unification pass on location plates for the next production.

Worked example

14-shot kitchen scene unified to one reference still in 40 minutes, then the look took 10.

Pitfalls

  • Creative grading first, you're grading 14 different films.
