The API

Versioned static JSON for agents and tools, generated from the research artifacts. Start at api/v1/index.json; full reference lives in API.md at the repo root.

Endpoints

api/v1/index.json

Manifest: version, endpoints, observation date, provenance.

api/v1/models.json

18 models with platform, type, credit costs, strengths, weaknesses, best use — plus an explicit unverified list.

api/v1/prompt-templates.json

31 templates (15 core, 8 animated, 8 photorealistic) with anatomy, use, and model notes.

api/v1/camera-movements.json

22-move camera lexicon with exact prompt phrasing and use cases.

api/v1/checklists.json

Pre-production, per-shot, continuity, audio, and delivery checklists.

api/v1/glossary.json

60+ AI film and production terms.

api/v1/festivals.json

$1M festival rules, prizes, jury, criteria, timeline — with winners marked pending.

api/v1/schema/

JSON Schema (draft-07) for models, prompt templates, and camera movements.

Usage notes

Credit costs were read from Higgsfield's live pricing page on 2026-10-10 and are denominated in Higgsfield credits per 5 seconds unless noted. Verify live before budgeting — the unverified array in models.json lists costs that could not be confirmed.

Template ids are stable (t1–t15 core, a1–a8 animated, p1–p8 photorealistic). Track is one of core, animated, photorealistic.

For language models

Agents should start with llms.txt (index) and llms-full.txt (the full guide text) at the repo root, then API.md.
