Style-bible builder.

Consistency is not a prompt trick — it is a document. Describe your character and world once, lock it into a STYLE LOCK block, and prepend that block verbatim to every generation in the production. Save named bibles in your browser; the prompt workshop can prepend any saved bible automatically.

Why this works

Long-form productions survive on reference discipline: one locked description of who and where, reused word-for-word so the model has no room to reinterpret between shots. The character-consistency and long-form pipelines chapters cover the system; this tool produces its core artifact. Rule of the lock: never paraphrase it — if the model drifts, regenerate the shot, don't rewrite the bible.
