Skill schema spec.

Every one of the 228 skills in skills/ follows this exact format — YAML frontmatter plus six Markdown sections. Build to it and your skills slot straight into this library, or any agent framework that reads it.

Specification

Frontmatter

Each skill file opens with a YAML frontmatter block carrying two required fields. name is the skill's machine id (lowercase, hyphens); description is the one-line trigger summary an agent reads when deciding whether to load the skill.

FieldRequiredFormat
nameYesLowercase slug, unique across skills/
descriptionYesOne sentence: what the skill does, in which track, using which source

Sections

After the frontmatter, the body is Markdown with an H1 title and these H2 sections, in order:

SectionRequiredPurpose
Use whenYesTrigger conditions: the situation, the anatomy at play, the models it applies to
InputsYesEvery placeholder or artifact the procedure needs, one per bullet
ProcedureYesNumbered steps an agent can execute verbatim; templates quoted exactly, never paraphrased
Worked exampleYesOne filled, realistic example showing the expected output shape
API referencesNoVersioned api/v1/ files the skill draws on
PitfallsYesThe known failure modes and how to avoid them

Full example

skills/prompts/prompt-a1.md — frontmatter first, then the rendered body:

name: prompt-a1
description: Write an anime action (sakuga) prompt (animated track) using the guide's template.

Prompt: Anime action (sakuga)

Use when

You are directing a shot that needs: anime action (sakuga). Anatomy: cel/sakuga/impact frames — NO lens or DOF language. Models: PixVerse (Anime), Vidu Q1, Pika.

Inputs

  • [CHARACTER] — fill per the template's anatomy

Procedure

  1. Gather one value per placeholder. Keep [STYLE] identical to every other prompt in the project.
  2. Fill the template verbatim — do not paraphrase its camera language:
  3. Cel-animated action cut: [CHARACTER] dashes forward, speed lines and impact frames, painted background holds still. Sakuga flourish on the strike. STYLE LOCK: bold colors, expressive features, dramatic lighting, hand-dra...
  4. Confirm exactly ONE primary motion and ONE camera move in the final prompt.
  5. Separate identity from motion: appearance descriptors in the Identity Block, action in the Motion Block — never pronouns alone as the subject anchor.
  6. Handle audio in post (this template's models don't do native audio well).
  7. Generate a 720p draft first; approve the select before any 1080p/4K render.

Worked example

Filled draft: Cel-animated action cut: [CHARACTER] dashes forward, speed lines and impact frames, painted background holds still. Sakuga flourish on the strike. STYLE LOCK: bold colors, expressive features, dramatic lighting, hand-drawn anime.

API references

  • api/v1/prompt-templates.json
  • api/v1/camera-movements.json

Pitfalls

  • Stacking two motions or two camera moves in one prompt — the model will split the difference and ruin both.
  • Changing the [STYLE] line between shots — the fastest route to a recast-looking cast.
