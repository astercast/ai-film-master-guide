# The AI Film Master Guide

**The playbook for professional-grade AI video production — aimed at one standard: entries that could win a $100,000 AI film festival.**

This repo is a living research project. Every claim traces back to a source (official docs, creator blogs, tutorial breakdowns, festival rules, winner analyses). See `sources/source-index.md` for the full catalog.

No site. No Vercel. This is a GitHub-only knowledge base.

## How to use it

1. **Start at `00-START-HERE.md`** — orientation + the $100K standard.
2. **Platform mastery** → `higgsfield/` — everything about making Higgsfield output look expensive.
3. **Craft** → `craft/` — the film school stuff that separates winners from everyone else (shot language, story, sound, edit).
4. **Platforms** → `platforms/` — when to use Runway, Kling, Sora, Luma, Pika, Hailuo instead — or alongside.
5. **Economics** → `economics/` — credit math, budget-friendly pro pipelines.
6. **Case studies** → `case-studies/` — what actual winning AI films did, shot by shot.
