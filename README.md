# The AI Film Master Guide

**The playbook for professional-grade AI video production — aimed at festival-winning quality.**

This repo is a living research project. Every claim traces back to a source (official docs, creator blogs, tutorial breakdowns, festival rules, winner analyses). See `sources/source-index.md` for the full catalog.

No Vercel. GitHub-only: a static generated site, the chapter sources, and a versioned JSON API.

## How to use it

- **Read the site:** open `site/index.html` (generated — rebuild after edits with `python3 scripts/build_site.py`)
- **Start at `00-START-HERE.md`** — orientation + the festival standard
- **Platform mastery** → `higgsfield/` — everything about making Higgsfield output look expensive
- **Craft** → `craft/` — shot language, story, sound, edit, character consistency
- **Platforms** → `platforms/` — when to use Runway, Kling, Sora, Luma, Pika, Hailuo instead — or alongside
- **Economics** → `economics/` — credit math, budget-friendly pro pipelines
- **Case studies** → `case-studies/` — festival winners and what made them win
- **Agents:** start at `llms.txt`, full text in `llms-full.txt`, API reference in `API.md`, data in `api/v1/`

## Site

`site/` is generated from the chapter Markdown by `scripts/build_site.py`
(markdown conversion in `scripts/md2html.py`). It includes:

- Landing with animated/stylized vs photorealistic track picker
- 14 chapter pages: sidebar nav, table of contents, prev/next
- Ctrl+K command palette (`assets/js/palette.js`, index in `site/search-index.json`)
- Human-readable API docs at `site/api.html`

Design: `assets/css/` (tokens, base, layout, components, docs). No frameworks, no build step beyond the Python generator, no external requests.

## API

`api/v1/` is generated by `python3 scripts/build_api.py` from the mega-research
artifacts (prompt library, checklists, model comparison, glossary, camera lexicon)
plus the hand-authored festival record. Commit the outputs.

- `index.json` — manifest
- `models.json` — 18 models with live credit costs + explicit unverified list
- `prompt-templates.json` — 31 templates (core / animated / photorealistic)
- `camera-movements.json` — 22-move camera lexicon
- `checklists.json` — production checklists
- `glossary.json` — 79 terms
- `festivals.json` — $1M festival rules/prizes/jury (winners pending)
- `schema/` — JSON Schemas

`skills/` — 173 agentic task procedures (`python3 scripts/build_skills.py`
regenerates from `api/v1/` data + authored procedures). `skills/index.json`
is the manifest agents should load first; `api/v1/index.json` points at it.
