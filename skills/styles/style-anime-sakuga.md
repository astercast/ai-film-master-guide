# Direct anime (sakuga)

## Use when

Anime action sequences and shorts.

## Inputs

- Character designs
- The action beats

## Procedure

1. Register: cel/sakuga/impact frames — NO lens or DOF language.
2. Painted backgrounds hold still; characters carry the motion.
3. Sakuga flourish on the strike: speed lines, impact frames, smears.
4. Style lock: bold colors, expressive features, dramatic lighting, hand-drawn.

## Worked example

Dash attack: speed lines + 3 impact frames, background frozen mid-pan.

## API references

- `api/v1/prompt-templates.json`
- `api/v1/models.json`

## Pitfalls

- Photoreal camera terms — they break the cel illusion instantly.
