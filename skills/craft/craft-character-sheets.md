# Build character sheet composites

## Use when

Any recurring character.

## Inputs

- Face anchor
- Wardrobe decisions

## Procedure

1. Close-up face anchor first — maximum identity detail.
2. Full-body looks built from the anchor: front/side/three-quarter.
3. Assemble as one composite; the sheet travels with every prompt.
4. Base portrait never re-run; variants masked around base pixels.

## Worked example

Mara sheet: face anchor + 3 full-body looks + 2 wardrobe states, one composite PNG.

## Pitfalls

- Single front photo as 'the sheet' — angles need angles.
