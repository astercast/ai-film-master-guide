# Stage with blocking diagrams

## What this gets you

Complicated multi-character shots will come out staged the way you drew them, not scrambled.

## Use when

See longform-blocking-diagram, this is the short-form version.

## Inputs

- Shot intent
- Character tags

## Procedure

1. Sketch the frame from the camera's front view.
2. Color per character; bind colors to @-tags in the prompt.
3. Attach last; address edits by color.

## Worked example

Two-shot argument: BLUE left foreground, RED right, prompt binds both.

## Pitfalls

- Top-down floor plans, models think in frames, not blueprints.
