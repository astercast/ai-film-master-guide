# Run the continuity ledger

## What this gets you

You will have a working ledger (the Continuity Ledger page) that tracks every character lock across a production and tells you when a scene is safe to generate.

## Use when

Before the first generation of any multi-shot production, and at the start of every shoot day after, consistency is where most festival entries die.

## Inputs

- Character list with identity system per character (Soul ID, character sheet, or reference upload)
- Wardrobe and prop descriptions, verbatim
- Location master stills
- Per-scene light locks (time of day + direction)

## Procedure

1. Work the five pre-generation locks in order: identity system chosen and trained; wardrobe description locked verbatim; location master stills approved; light direction + time of day locked per scene; start frame is real (approved frame or trained identity), never invented.
2. Log every lock the film depends on, identity, wardrobe, prop, location, lighting, era / grade, with the verbatim wording or the reference it is locked to.
3. Mark each lock's state honestly after every batch: locked, drifted, or broken. A drifted lock gets re-locked before the next generation; drift compounds shot over shot.
4. Apply the rejection rules to every clip: it fails if the face drifts, the wardrobe changes, the light flips, or the camera moves without motivation.
5. Never chain from a failed clip, failed clips get re-prompted from the last approved frame; keep every approved still in the frame library for new shots to start from.

## Worked example

Worked example on the ledger (continuity.html): a 6-lock AI-short ledger, 5 locks holding, 1 wardrobe lock drifted, reads 'Hold' until the wardrobe line is re-locked verbatim, then 'Continuity clean'.

## Pitfalls

- Relying on a text description alone to hold a face across 50 shots, the weakest rung of the identity stack.
- Improvising a mid-film wardrobe change per shot instead of writing a new locked description.
- Chaining from a failed clip because it was expensive, every later shot inherits the break.
