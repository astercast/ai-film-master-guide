# Run the de-plasticize stack

## Use when

Any AI footage that reads synthetic.

## Inputs

- Unified timeline

## Procedure

1. Desaturate 10–20% (AI oversaturates by default).
2. Add fine 35mm grain — breaks up synthetic gradients.
3. Subtle chromatic aberration at high-contrast edges.
4. Soften, don't sharpen. Skin last, on a big screen.

## Worked example

Portrait CU: -15 sat, grain, 2px CA — reads as 16mm film.

## Pitfalls

- Skipping grain — it's the single fastest anti-plastic pass.
