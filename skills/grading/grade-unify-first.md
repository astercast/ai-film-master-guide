# Unify before grading

## What this gets you

All your shots will match each other, same light, same colour world, before any creative look is applied, so the film stops looking stitched from different cameras.

## Use when

Start of the color pass.

## Inputs

- Locked picture
- One hero reference still per scene

## Procedure

1. Per scene: match exposure, white balance, and contrast curve to the reference, scopes, not eyes.
2. Match saturation (AI generations vary wildly).
3. Only then apply the creative look.
4. Consider a pre-generation unification pass on location plates for the next production.

## Worked example

14-shot kitchen scene unified to one reference still in 40 minutes, then the look took 10.

## Pitfalls

- Creative grading first, you're grading 14 different films.
