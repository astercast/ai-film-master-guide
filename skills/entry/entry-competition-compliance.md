# Check competition delivery compliance

## Use when

Before starting AND before submitting a competition entry.

## Inputs

- Your film's production log
- The current official rules page

## Procedure

1. All video/image generated on higgsfield.ai — no outside plates as final pixels.
2. No real person's face or voice as input — even your own.
3. Music/voice/SFX all AI-generated, uploaded into the project, rights held.
4. Runtime ≥ 3:00, 16:9 or 21:9, watermark + packshot on the submission.
5. Public social post of the same video (Instagram/YouTube/X/Reddit, public, no login).
6. Re-verify the rules page at submission time — rules move.

## Worked example

Compliance pass on a 4:12 entry: all-Seedance ✓, no real faces ✓, AI audio w/ rights ✓, 21:9 ✓, watermark+packshot ✓, public post ✓ → submit.

## API references

- `data/v1/competitions.json`

## Pitfalls

- Assuming last month's rules still hold — re-read the official page every time.
