# Direct TTS voices through text

## What this gets you

Your text-to-speech voices will sound directed, because you will write the punctuation, pauses and emphasis that are the only controls these tools give you.

## Use when

Any AI voiceover on v3/v4 models.

## Inputs

- The script
- The voice

## Procedure

1. Ellipsis for hesitation, dashes for interruptions, capitalization for stress.
2. Bracketed stage directions: [whispering], [laughs]; v4 adds environmental descriptors ([light rain], [door slams]).
3. Settings: Stability 0.4–0.6 for expressive dialogue (higher = flatter), similarity boost 0.7–0.8 for clones, style exaggeration 0–0.3.
4. Write performance arcs, not flat tones: open serious → build insistent → close warm.
5. Test the voice on your actual dialogue before committing it to a main character; regenerate broken lines, not whole scripts.

## Worked example

[sighs] 'I told you...' — ellipsis + sigh tag turned a flat read into a confession.

## Pitfalls

- Leaving Stability at default for emotional scenes — you get a newsreader.
