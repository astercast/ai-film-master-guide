# Write the director's read

## Use when

Ensemble scenes, before the shotlist.

## Inputs

- The scene script

## Procedure

1. Name the ONE event every character is living through.
2. Assign each character a physical channel (hands, jaw, feet, breath).
3. Write it down and share it — this is the scene's performance bible.
4. Generate against it; audit drafts against it.

## Worked example

Event: the verdict is read. Mara's channel: hands. Vex's: jaw. The kid's: feet.

## Pitfalls

- Skipping this — four mannequins emoting at the camera.
