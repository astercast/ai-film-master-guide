# Run the restraint pass

## What this gets you

Your characters will stop over-acting: smaller, quieter, more believable performances, directed with restraint instead of melodrama.

## Use when

Any AI performance that reads as soap opera.

## Inputs

- The performance prompt

## Procedure

1. Add negative constraints: no eyebrow raises, no wide-eyed gasps, no forced tears.
2. Replace stated emotion with the situation that produces it.
3. Let weather, light, and objects carry mood so the face doesn't have to.
4. Under-specify the face deliberately, let the model find expressions itself.
5. Widen the framing: pushed-in over-directed close-ups expose every flaw.

## Worked example

Meltdown scene: removed 'devastated', wrote 'she keeps refolding the letter so he won't see her hands shake', the take landed.

## Pitfalls

- Directing harder when the take fails, direct less, not more.
