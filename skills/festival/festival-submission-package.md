# Assemble the submission package

## Use when

The final 48 hours before deadline.

## Inputs

- Locked film
- Title art
- Social accounts

## Procedure

1. Render the final with the required watermark burned in.
2. Design the packshot: title, key art, credits — festival-grade, not an afterthought.
3. Post the identical video publicly (IG/YouTube/X/Reddit) — public, no login wall.
4. Keep the post live through judging; don't privatize early.

## Worked example

Checklist: watermarked master ✓, packshot 1920×1080 ✓, YouTube public post with festival hashtag ✓.

## API references

- `api/v1/festivals.json`

## Pitfalls

- Forgetting the packshot until deadline night — it's a judging touchpoint.
