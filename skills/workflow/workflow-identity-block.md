# Write the Identity Block

## What this gets you

You will be able to describe a character once, in a reusable block, so they look identical every time they appear.

## Use when

Every prompt with a recurring character.

## Inputs

- Locked character sheet
- @ reference or stable label

## Procedure

1. Face, hair, wardrobe, palette, static facts only.
2. Anchor with a stable label or @ reference, never pronouns alone.
3. No action verbs, no camera language in this block.

## Worked example

IDENTITY: MARA, late 20s, copper bob, black leather jacket, gold hoop earring. @mara_ON_neon_v1.

## Pitfalls

- Letting 'she walks' sneak into the identity block, that's the motion block's job.
