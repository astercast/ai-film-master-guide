# Walk the Path — the sequenced curriculum

## Use when

Starting the guide from zero, onboarding a collaborator, or finding the hole in a self-taught practice — whenever the question is 'what do I learn next', not 'how do I do this one thing'.

## Inputs

- data/v1/curriculum.json — the six stages and their skill order
- The learner's honest current stage (the last milestone they can actually demonstrate)
- A production, however small, to practise each stage on

## Procedure

1. Read the stage map first (path.html): six stages in production order — First Light (the prompt and the camera), The Look, the Voice (the style tracks), The Instrument (choosing the model), Direction (craft, performance, workflow), Production (recipes, series, the long form), The Finish (repair, grade, deliver, ship).
2. Start at the first stage whose milestone you cannot already demonstrate — not at stage one by default, and not at the stage you wish you were on. The milestones are demonstrations, not vibes: write the shot, choose the model with evidence, direct the beat, run the production, ship the film.
3. Work a stage's skills in the Path's order, checking each off on path.html only when it has been done on a real production — read is not done. Progress persists in the browser (localStorage); the map is the record.
4. Do not skip the stage gates to reach a favourite tool: the sequence is the curriculum's claim — models before direction is shopping, production before direction is expensive wandering, the finish before production is polish on footage that should have been re-planned.
5. At a stage's end, run its milestone as a test on the current production. If it fails, the stage is not finished — the failing skills are the next work, in order. If it passes, move on and do not look back; the later stages exercise the earlier ones.
6. Keep the homepage's 'Pick your path' goal routes for what they are — a handful of chapters per goal, for a deadline. The Path is the whole library, for the craft.

## Worked example

A new learner opens path.html at Stage 1 (37 skills: the 15 core prompts, then the 22 camera moves), checks them off across their first short, and reaches Stage 3's milestone — name the model, the fallback, and the evidence — before spending on a flagship model. Full map: path.html; data: data/v1/curriculum.json (241 skills, each exactly once).

## Pitfalls

- Checking skills off for reading them — the Path counts done-on-a-production, the same standard the sheets apply: what is written down and exercised, not intentions.
- Walking the stages out of order because a later tool looks more fun — the gaps surface later at production prices; the sequence exists so they surface at practice prices.
- Confusing the Path with the homepage's goal routes — those order 4–5 chapters toward one goal; the Path orders all 241 skills toward the whole craft.
