# Debug a failing prompt

## Use when

When a prompt keeps missing.

## Inputs

- The failing prompt
- The last three outputs

## Procedure

1. Name the single failure (blocking? face? motion? style?).
2. Change ONE variable: the blocking phrase, the reference order, or the motion verb.
3. Never re-roll the identical prompt hoping — hope isn't a variable.
4. After three failures, simplify the shot: fewer elements, tighter framing.

## Worked example

Face keeps morphing → moved the face-anchor reference to last position (photos win the style vote) → locked.

## Pitfalls

- Changing three things at once — you'll never know what fixed it.
