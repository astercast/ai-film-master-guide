# Write the Motion Block

## Use when

Every prompt, every shot.

## Inputs

- The shot's one job
- Chosen camera move

## Procedure

1. One subject, one action verb, one camera move.
2. Name speed and stability, not just the move.
3. If you need two actions, you need two shots.

## Worked example

MOTION: Mara crosses the kitchen in three strides, sets the ledger down. Slow dolly-in, eye level.

## API references

- `data/v1/camera-movements.json`

## Pitfalls

- 'She walks over, picks it up, and turns' — three shots wearing a trench coat.
