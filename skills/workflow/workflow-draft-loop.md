# Run the 720p draft loop

## Use when

All generation until the select is locked.

## Inputs

- Shotlist
- Cheapest tier that answers the creative question

## Procedure

1. Generate drafts at 720p/fast tier.
2. Review against the shot's one-line goal — not against perfection.
3. Select or re-roll with a changed variable (never the same prompt twice).
4. Escalate ONLY selects to hero resolution.

## Worked example

12 drafts for a 6-shot scene at 720p: 6 selects → 6 hero renders. 50% of the budget never spent.

## API references

- `api/v1/models.json`

## Pitfalls

- Rendering hero quality 'to see it properly' — that's what the draft is for.
