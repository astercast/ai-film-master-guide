# Choose a model for stylized 3D

## What this gets you

You will know which model delivers that polished animated-feature look for stylised 3D characters.

## Use when

Family, comedy, character-driven stylized work.

## Inputs

- Character design refs
- Performance needs (squash-and-stretch?)

## Procedure

1. Shortlist: PixVerse (3D mode), Pika, Soul Cinema keyframes → Kling I2V.
2. Design for big readable shapes: expressive eyes, soft forms.
3. Squash-and-stretch in-prompt for comedy beats.

## Worked example

Character reaction beat: PixVerse 3D, squash-and-stretch surprise take, warm key light.

## API references

- `data/v1/models.json`

## Pitfalls

- Photoreal lighting language, stylized 3D wants soft, simple light.
