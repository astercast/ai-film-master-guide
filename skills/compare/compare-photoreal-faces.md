# Choose a model for photoreal faces

## Use when

Dialogue close-ups, character pieces, beauty work.

## Inputs

- Shot scale (ECU/CU/MCU)
- Need for micro-expression

## Procedure

1. Shortlist: Hailuo 2.3/02, Veo 3.1, Soul ID + Kling for locked identity.
2. Ration close-ups — micro-acting is the weakest link; spend them at emotional peaks.
3. For recurring characters, train/lock identity (Soul ID) rather than describing faces per prompt.

## Worked example

Emotional peak close-up: Hailuo, soft window light, slow push-in, ONE micro-expression named.

## API references

- `data/v1/models.json`

## Pitfalls

- Wide-shot faces — plasticky and drifty; punch in or fix in post.
