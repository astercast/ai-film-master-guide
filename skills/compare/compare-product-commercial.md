# Choose a model for product commercials

## Use when

Product spots, food, fashion film.

## Inputs

- Product type
- Need for macro detail vs lifestyle context

## Procedure

1. Shortlist: Wan 2.6 (camera-first), Seedance 2.0, Kling 3.0.
2. One move + one focus event per shot (orbit + focus pull).
3. Texture and steam/sheen sell product — prompt them explicitly.

## Worked example

Watch commercial: macro orbit + focus pull from crystal to dial, Wan 2.6, warm rim light.

## API references

- `api/v1/models.json`
- `api/v1/prompt-templates.json`

## Pitfalls

- Lifestyle context stealing focus — product is the hero, environment is the frame.
