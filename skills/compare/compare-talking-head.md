# Choose a model for talking heads

## Use when

Testimonials, UGC, documentary interviews.

## Inputs

- Script lines
- Framing (MCU typical)

## Procedure

1. Static tripod framing, eye-level, clean front face.
2. Short lines per generation; native dialogue quotes where supported.
3. Marketing Studio or Kling 3.0 for reliability; Pika for lip-sync passes.

## Worked example

Testimonial: MCU, warm studio bokeh, static, 8-second lines, quoted dialogue.

## API references

- `data/v1/models.json`

## Pitfalls

- Camera drift on a 'static' shot — say 'locked-off tripod' explicitly.
