# Run the entry-killer audit

## Use when

Before submitting to any competition.

## Inputs

- Locked cut

## Procedure

1. No morphing faces, extra limbs, shifting wardrobe across cuts.
2. No shot exists just to show off a model — every shot serves story.
3. Sound designed like a film: custom music, voices, layered foley.
4. One committed POV/style held across the runtime.
5. A human edit is felt: pacing, turns, button image.

## Worked example

A hyped contest winner with three-eyed cyclopses — the hype didn't forgive the continuity.

## API references

- `api/v1/checklists.json`

## Pitfalls

- Submitting the day you finish — sleep on it, audit cold, then submit.
