# Run an async remote production

> **Reference skill** — kept for the record, for agents, and for later: not a first-project skill. See SKILLS_AUDIT.md (rotation 20).

## What this gets you

Reference for later: how a small team in different time zones makes one film together — one shared project, jobs split by craft, no drift between collaborators.

## Use when

Collaborating across time zones on an AI film.

## Inputs

- Director's intent doc (one page)
- Shared Higgsfield/Cinema Studio project
- Discipline split

## Procedure

1. Write the one-page intent doc: logline, tone refs, the emotion each act must land.
2. Work in ONE shared project — every prompt, generation, and select visible to all.
3. Split by discipline (performance/character vs camera/action), not by scene.
4. Lock the style bible day one; review selects daily.

## Worked example

GRANDMA vs WASP: two directors, never met, $150K — one vision, distributed labor, 8,752-entry field.

## Pitfalls

- Splitting by scene — that's how two halves of one film stop matching.
