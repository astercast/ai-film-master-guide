# Chain scenes with video references

## What this gets you

Each new scene will start from your last finished scene's actual video, so the film flows as one piece instead of drifting apart shot by shot.

## Use when

Moving from one scene to the next in a multi-scene production.

## Inputs

- Previous scene's finished video
- Current scene's shotlist

## Procedure

1. Export the previous scene's final video.
2. Attach it as the character/location reference for the next scene's generations.
3. A text description drifts over generations, a video reference doesn't.
4. Re-anchor original asset references every few chained generations anyway.

## Worked example

Scene 8 references scene7_final.mp4 for Mara's look + kitchen state, plus the registry plates.

## Pitfalls

- Chaining from a flawed scene, errors compound. Only chain from approved selects.
