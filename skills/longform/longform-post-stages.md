# Run the five post stages

## What this gets you

You will have a finishing order for a long film — assembly, rough cut, supervision, fine cut, lock — so 'nearly done' stops lasting forever.

## Use when

Post-production on any multi-minute AI film.

## Inputs

- All selects
- Edit timeline
- Cold viewers for the fine cut

## Procedure

1. 1. Assembly: scenes in script order, no rhythm.
2. 2. Rough cut: find the film's actual shape.
3. 3. Generation supervision: ONE scheduled QC/re-generation pass — not continuous re-rolling.
4. 4. Fine cut: screen for cold viewers, cut what they don't feel.
5. 5. Picture lock: no new generations except emergencies, with notice to color and sound.
6. Colorist's job = unification: every generation ships its own grade.

## Worked example

After the rough cut revealed 11 broken shots, one supervision pass re-generated them in two days — then lock.

## Pitfalls

- Re-rolling continuously during the edit — schedule it, then stop.
