# Stress-test a scene before generating

## Use when

Before spending a single credit on a scene.

## Inputs

- Scene script
- The scene's one-sentence dramatic question

## Procedure

1. State each character's Goal, Obstacle, Tactic in the scene.
2. Name the Reversal (what flips) and the Value Shift (what changes).
3. Verdict: weakest point + concrete fix.
4. Only generate scenes that pass — a weak scene's cost is discovered after you've paid for it.

## Worked example

Scene 12: Mara's goal (get the ledger), obstacle (Vex won't open the safe), tactic (charm → threat). Reversal: the safe is empty. Weakest point: no visual action — fix: Mara pockets a decoy ledger.

## Pitfalls

- Skipping this because 'it's just AI' — the most expensive sentence in long-form.
