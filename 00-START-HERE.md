# Start Here

Read this first. It sets the standard everything else in this repo is measured against.

## The goal

Produce AI video at the level of a **$100,000-prize AI film festival entry**. Not "good for AI video." Good, full stop — the kind of work that holds up on a big screen next to traditionally shot films.

## What the judges actually reward

Distilled from festival rules, judging criteria, and winner breakdowns across the research in this repo:

1. **Story first.** A tight arc beats pretty pixels. Most AI-film losers are tech demos with no second act.
2. **Intentional camera.** Every move motivated — dolly, crane, orbit, handheld — never default drift.
3. **Consistency.** Same face, same wardrobe, same world, shot to shot. This is where 90% of entries die.
4. **Sound.** Native ambient audio, designed SFX, score that serves the story. Silent or stock-music films read amateur.
5. **Restraint.** Fewer, better shots. A 2-minute film with 12 locked-in shots beats 40 flashy ones.

## The pipeline this guide teaches

```
Story → Shot list → Character lock (Soul ID / references)
  → Prompt craft per shot → Generation (one shot at a time, quality-checked)
  → Selects → Assembly edit → Sound design → Color → VFX touch-up
  → Export to spec → Festival submission
```

## What this guide is not

- Not a list of links. Every chapter distills technique into rules you can apply tonight.
- Not hype. If a model can't do something reliably, this guide says so and gives the workaround.
- Not finished. It's a research engine — new sources get folded in, weak advice gets cut.

## The one rule

**Never spend credits on a guess.** Every generation run follows the guide's checklists. A clip that fails the quality gate doesn't chain — it gets re-prompted.
