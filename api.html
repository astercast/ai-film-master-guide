The API

Versioned static JSON for agents and tools, generated from the research artifacts. Start at api/v1/index.json; full reference lives in API.md at the repo root; the operator's manual is AGENT.md.

Try the API

Pick an endpoint and fetch it live — the console reads the same api/v1/ files this page documents. Static JSON: no auth, no keys, no rate limits.

Select an endpoint and press Fetch JSON.

Endpoints

api/v1/index.json

Manifest: every endpoint with description, schema URL, updated timestamp, record counts, and deprecation notes. Start here.

api/v1/models.json

29 models with platform, type, credit costs, strengths, weaknesses, best use — plus per-model last-verified dates, status, and an explicit unverified list. Sora is discontinued.

api/v1/prompt-templates.json

47 templates (15 core, 8 animated, 8 photorealistic, 5 performance, 4 audio, 4 longform, 3 repair) with anatomy, use, and model notes.

api/v1/camera-movements.json

22-move camera lexicon with exact prompt phrasing and use cases.

api/v1/checklists.json

Pre-production, per-shot, continuity, audio, and delivery checklists.

api/v1/glossary.json

79 AI film and production terms.

api/v1/competitions.json

Judged competitions as craft records: what they judge, production constraints, craft lessons. No prizes or deadlines.

api/v1/teardowns.json

7 shot-by-shot teardowns; prompt reconstructions are analytical, not actual prompts.

api/v1/diagnoses.json

12 failure diagnoses: symptom → craft diagnosis, fixes, repair-template link.

api/v1/model-checks.json

Model-watch freshness feed: per-model last check, source-signature diffs, news headlines.

api/v1/model-review-queue.json

Pending model-watch review items. Empty array = nothing pending.

api/v1/schema/

JSON Schema (draft-07) for every endpoint: index, model, prompt-template, camera-movement, checklist, glossary, competition, teardown, diagnosis, model-checks, model-review-queue.

Usage notes

Credit costs were read from Higgsfield's live pricing page on 2026-10-10 and are denominated in Higgsfield credits per 5 seconds unless noted. Verify live before budgeting — the unverified array in models.json lists costs that could not be confirmed.

Template ids are stable (t1–t15 core, a1–a8 animated, p1–p8 photorealistic). Track is one of core, animated, photorealistic, performance, audio, longform, repair.

For language models

Agents should start with llms.txt (index) and llms-full.txt (the full guide text) at the repo root, then AGENT.md — the operator's manual with four end-to-end workflows — then API.md.
