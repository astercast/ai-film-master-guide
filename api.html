Endpoints00:01:30:00

data/v1/index.json

Manifest: every endpoint with description, schema URL, updated timestamp, record counts, and deprecation notes. Start here.

data/v1/models.json

32 models with platform, type, credit costs, strengths, weaknesses, best use, plus per-model last-verified dates, status, and an explicit unverified list. Sora is discontinued.

data/v1/prompt-templates.json

47 templates (15 core, 8 animated, 8 photorealistic, 5 performance, 4 audio, 4 longform, 3 repair) with anatomy, use, and model notes.

data/v1/camera-movements.json

22-move camera lexicon with exact prompt phrasing and use cases.

data/v1/checklists.json

Pre-production, per-shot, continuity, audio, and delivery checklists.

data/v1/glossary.json

79 AI film and production terms.

data/v1/competitions.json

Judged competitions as craft records: what they judge, production constraints, craft lessons. No prizes or deadlines.

data/v1/teardowns.json

10 shot-by-shot teardowns; prompt reconstructions are analytical, not actual prompts.

data/v1/diagnoses.json

12 failure diagnoses: symptom → craft diagnosis, fixes, repair-template link.

data/v1/model-checks.json

Model-watch freshness feed: per-model last check, source-signature diffs, news headlines.

data/v1/model-review-queue.json

Pending model-watch review items. Empty array = nothing pending.

data/v1/model-review-log.json

Watchtower review log: every checker flag re-fetched and given a verdict with its basis before the queue clears. A cleared queue is an audited queue.

data/v1/pricing.json

Curated pricing table: 32 models with per-tier USD rates (per second / per clip / per image), basis and confidence per tier.

data/v1/model-history.json

Watchtower 2.0 event log: 86 dated status, price, tier, release, verification, and coverage events, plus the 2026-10-11 pricing baseline the drift engine diffs against.

data/v1/schema/

JSON Schema (draft-07) for every endpoint: index, model, prompt-template, camera-movement, checklist, glossary, competition, teardown, diagnosis, model-checks, model-review-queue, model-history, model-review-log.

Live functions, The Watchtower00:01:30:00

On the deployed site the same data is served live by six Vercel serverless functions (zero npm dependencies). The frontend calls the function first with a 7 second timeout and falls back to the static data/v1/ file, the badge next to each widget reads live, waking server…, or cached · updated HH:MM. Full reference in API.md; deploy runbook in GO_LIVE.md.

  • GET /api/health, status, function roster, data-freshness SLAs.
  • GET /api/models-status, 32-model freshness join; honestly degraded when sources failed.
  • GET /api/models-pricing, the curated pricing table (?model_id= filter).
  • GET /api/models-changes, Watchtower 2.0: events since ?since=, the mechanical pricing diff against the 2026-10-11 baseline, and drift alerts for all 32 models.
  • POST /api/calc-cost, {model_id, seconds, resolution_tier, clips} → cost envelope with full 400/404 validation.
  • GET /api/cron/watchtower, daily incremental refresh (CRON_SECRET bearer); flags, never auto-edits.

Usage notes00:02:15:00

Credit costs were read from Higgsfield's live pricing page on 2026-10-10 and are denominated in Higgsfield credits per 5 seconds unless noted. Verify live before budgeting, the unverified array in models.json lists costs that could not be confirmed.

Template ids are stable (t1 to t15 core, a1 to a8 animated, p1 to p8 photorealistic). Track is one of core, animated, photorealistic, performance, audio, longform, repair.
